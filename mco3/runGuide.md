# MCO3 Run Guide - Group 15

## Rust
```bash
cd apps/load_calculator && rustc MP_15_Rust.rs && ./MP_15_Rust
cd apps/corpus_analysis && rustc MP_15_Rust.rs && ./MP_15_Rust
```

## Kotlin
```bash
cd apps/load_calculator && kotlinc MP_15_KT.kt -include-runtime -d MP_15_KT.jar && java -jar MP_15_KT.jar
cd apps/corpus_analysis && kotlinc MP_15_KT.kt -include-runtime -d MP_15_KT.jar && java -jar MP_15_KT.jar
```

## R
```bash
cd apps/load_calculator && Rscript MP_15_R.R
cd apps/corpus_analysis && Rscript MP_15_R.R
```

## JavaScript
```bash
cd apps/load_calculator && node MP_15_JS.js
cd apps/corpus_analysis && node MP_15_JS.js
```
